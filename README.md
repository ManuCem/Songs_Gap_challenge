# 🎵 Lyrics Gap Challenge

A small web app for practising English listening: paste the lyrics of any song, choose how many words to hide, and fill in the gaps while you listen.
You can check your answers at any time, and the Solution tab shows the full lyrics without erasing what you've written in the Challenge tab.
It runs entirely in the browser (a single `index.html`, nothing to install).

**▶ Try it here: https://manucem.github.io/Songs_Gap_challenge/**
