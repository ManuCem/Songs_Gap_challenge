# 🎵 Lyrics Gap Challenge

A web app for learning English with music: search any song, pick a level and fill in the missing lyrics while it plays, with typing, multiple-choice and karaoke-style listen-along modes.
Sign in with Google to save songs with labels, earn XP and daily streaks, climb per-song leaderboards and practise the words you miss most.
It runs entirely in the browser (GitHub Pages + Firebase + the free LRCLIB lyrics API) and can be installed on your phone like an app.

**▶ Try it here: https://manucem.github.io/Songs_Gap_challenge/**
